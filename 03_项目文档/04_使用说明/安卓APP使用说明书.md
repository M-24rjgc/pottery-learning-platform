# 非遗之手 · 安卓 App 使用说明书

适用于 0.2.0 内部体验版。手机用于辅助学习与查看记录，电脑负责手套连接和数据保存。

## 1. 安装前准备

- 安卓手机：Android 7.0 或以上，系统 WebView 可正常使用。
- 已启动非遗之手工作台的电脑、可使用的手套。
- 手机和电脑连接同一 Wi-Fi 或可互通的局域网。

安装文件为 `非遗之手-0.2.0-debug.apk`，本地位于 `05_交付归档/安卓APP/`。这是内部调试签名版本，未上架。以项目提供的文件为准，不安装已撤回的0.3.0版本。

## 2. 安装 App

1. 把 APK 传到手机，在文件管理器中打开。
2. 按系统提示允许本次安装来源，完成安装。
3. 打开“非遗之手”。首次安装和部分机型的系统提示可能不同。

更新时优先使用相同签名覆盖安装。签名不同可能无法升级；不要急着卸载，卸载会清除手机缓存和连接设置。电脑里的报告不会因为卸载 App 被删除。

## 3. 第一次连接电脑

1. 在电脑启动工作台并连接手套。
2. 在电脑“设置 → 两端协同 → 查看局域网地址”查看地址。
3. 在 App 打开“连接电脑”，填写电脑地址，例如 `192.168.1.20:4180`，确认连接。
4. 返回首页，确认电脑在线；再到“设备”查看手套数据是否更新。

不要填写 `localhost` 或 `127.0.0.1`；不要使用电脑上虚拟网卡的地址。电脑更换 Wi-Fi 后地址可能改变，需要重新填写。手机端不直接扫描连接手套蓝牙。

## 4. 三个主要入口

| 入口 | 能做什么 |
|---|---|
| 学习 | 查看课程示范、进入练习、查看练习反馈 |
| 设备 | 查看主机与手套状态、五指读数、校准状态和软件参考 |
| 我的 | 查看学习记录、打开报告、设置连接和个人信息 |

界面资源随安装包提供；教学视频从电脑读取。手机没连接电脑时，不能把图片或缓存当成实时数据。

## 5. 开始一段练习

1. 先在电脑完成手套校准，并录入有效参考姿态。
2. 在 App 进入练习；开始前需要电脑已连接手套且有新鲜采样。
3. 观看示范，按自己的节奏练习，查看五指变化和反馈。
4. 需要休息时暂停，准备好后继续。
5. 结束时填写备注并确认结束，查看生成的报告。

手机和电脑控制同一场练习，不是各自创建独立副本。任一端暂停或结束会影响另一端。退出 App、切后台或锁屏不等于结束电脑上的练习；练完请明确点击结束。

当前匹配针对已录入的静态参考，不会自动理解视频中的完整动作。动作正确但不匹配时，请先核对参考及校准，不必强行摆到某个数值。

## 6. 校准与参考

App 可查看校准状态；握拳、张开的实际硬件端点采集请在电脑首页“重新校准”完成。

App 可查看和新增软件参考。录入时保持目标姿态，填写名称、类型与容差后保存。它不覆盖手套的十个硬件槽位。新校准会影响旧参考的可用性，建议在当前佩戴和校准下重新核对或录入。

## 7. 报告、分享与离线查看

在学习记录中打开报告，可查看时长、采样帧数、匹配次数、时间线和备注。分享功能调用安卓系统分享面板，分享的是报告摘要；选择接收人并发送由你完成。

报告主要保存在电脑。手机保留最近同步的最多50份报告用于离线查看。断网时不能开始或修改练习；重新连上后再继续操作。不要将缓存数值视作手套实时状态。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 连接不上电脑 | 确认服务开启、IP和4180端口正确、同一网络；避免访客Wi-Fi隔离 |
| 电脑在线，手套离线 | 到电脑检查手套供电、蓝牙和采集模式 |
| 看不到视频 | 视频从电脑读取，先检查主机连接和电脑侧视频播放 |
| 开始练习不可用 | 需要电脑在线、手套有实时采样，且没有冲突操作 |
| 匹配次数为0 | 校准不等于录入参考；核对有效模板和容差 |
| 手机没有语音 | 当前 App 未提供独立的姿态语音播报；电脑语音也有练习状态及匹配触发条件 |
| 锁屏后数据停住 | 返回 App 等待重新同步，确认显示在线后再操作 |
| 分享无法完成 | 系统分享需手机真机和可用接收应用，浏览器预览不能替代真机验证 |

## 附录：重新打包与技术位置

工程目录为 `01_软件工程/pottery-app`。已配置电脑可运行 `npm run apk` 或双击 `打包安卓APP.cmd`。新 Windows 环境：

```powershell
npm ci
powershell -ExecutionPolicy Bypass -File scripts/setup-toolchain.ps1
npm run apk
```

当前工程使用 Node.js22+、JDK21、Android API36、Capacitor 和 Gradle。构建脚本生成调试 APK、校验签名并归档；私钥和本地工具链不进入 Git。

日常验证：`npm test` 检查客户端逻辑；`npm run build` 构建前端。源码入口为 `src/App.jsx`，页面在 `src/StudioView.jsx`，主机通信在 `src/api.js`，原生安卓壳在 `android/`。

iOS 工程也保留，但本说明不承诺已有苹果安装包。安卓真机首次安装、分享、网络切换和锁屏恢复仍应在目标手机上验收。
