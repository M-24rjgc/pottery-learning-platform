# 非遗之手 · 电脑 Web 使用说明书

适用于 2026 年 9 月 14 日桌面工作台。面向教师、学习者及现场联调人员。

## 1. 先认识这套软件

电脑是主机：连接手套、展示五指数据、完成校准、保存参考和练习报告。安卓 App 连接电脑共享练习，不需要把手套同时连接到手机。

第一次使用按这个顺序：**启动工作台 → 连接手套 → 校准 → 录入参考 → 开始练习 → 结束并查看报告**。

目前参考比较的是一个时刻的五指姿态，不会自动从示范视频提取标准动作，也不等于完整揉泥过程的专业评分。

## 2. 启动与页面入口

在已配置好的项目电脑上，双击总目录的 `启动非遗之手.cmd`，打开 http://localhost:4180/ 。练习期间保持电脑及服务运行。

| 页面 | 用途 |
|---|---|
| 训练工作台 | 看示范、看实时曲线、启动练习、查看反馈、打开快速校准 |
| 设备与校准 | 扫描连接手套、检查模式、查看命令回执及硬件配置 |
| 手势管理 | 新增、查看、导入、导出和删除软件参考 |
| 学习记录 | 查找历史练习、打开报告 |
| 设置 | 学习者名称、语音开关、默认容差、局域网地址 |

## 3. 通过蓝牙连接手套

1. 给手套开机，打开电脑蓝牙。
2. 进入“设备与校准”，在“真实手套接入”点击“扫描蓝牙手套”。
3. 选择扫描到的 `Glove`，连接主机。若有多个同名设备，先确认桌面设备。
4. 确认显示蓝牙已连接、采样正在更新。回到首页，逐个轻动手指，观察五路数值。
5. 如果设备在模式 1，切回“采集模式0”以获得连续曲线。模式 1 的硬件识别事件和软件姿态匹配是两条不同链路。

先确认数据更新，再校准。连接成功只表示通信建立，不表示佩戴、校准或参考已经正确。

## 4. 在首页完成校准

结束当前练习后进行。戴好手套、固定佩戴位置，手臂自然放在桌面。

1. 在首页右侧“设备快捷操作”点击 **重新校准**，弹窗左侧为姿态图示，右侧为实时五指数值与曲线。
2. **握拳**：五指自然弯曲，拇指收拢，不要用力攥紧。保持约一秒，点击“采集握拳端点”，等设备确认。
3. **张开**：五指自然伸直、拇指展开，保持稳定，按弹窗按钮采集张开端点。
4. **检查**：再次握拳、张开，观察每根手指是否有明显变化；映射后通常握拳接近 500、张开接近 2500。
5. 确认效果后点击保存，等待手套回执。仅关闭弹窗不会撤销已采集的端点，也不等于保存到手套。

如果提示姿态不稳定、某根手指变化不足或数据过期，先处理提示再重试。数值 500–2500 是映射值，不是压力或角度；一直处于端点可能与佩戴、校准或传感器有关，不能仅据此判定损坏。

重新校准后旧软件参考会进入待复核状态，不继续参与匹配。当前手势卡片尚未完整展示该状态，因此建议校准后重新录入需要使用的参考，给名称加上日期以便区分。

## 5. 录入一个软件参考

1. 在“手势管理”选择“录入手势”。
2. 输入清晰的名称，例如“按压准备－张老师－0914”。
3. 选择“正确姿态”或“待纠正姿态”。后者匹配后用于提示调整，不作为正确匹配。
4. 设置容差；容差表示每根手指与参考值允许的最大差值。过小会难以复现，过大会把不同姿态混在一起，应结合实际重复动作核对。
5. 保持目标姿态，核对弹窗读数后点击“采集并保存”。当前版本保存点击时的一组五指值，不是录制整段动作。
6. 先离开该姿态，再重新做一次，检查能否复现。录错了就重新录入，不要用随意放大容差来掩盖错误参考。

“手势管理”操作的是软件参考。设备页的“录入所选槽位”会覆盖手套硬件槽位，是另一项操作；日常软件练习无需使用它。硬件原有模板无法通过当前蓝牙完整列出，不要把读取失败当作空槽。

## 6. 练习、反馈与语音

观看首页“揉泥基础”参考视频，按需选择正面、侧面或近景。点击“开始练习”后，工作台累计时长、采样帧数及匹配次数；可暂停、继续和结束。

软件将五指同时与有效参考比较：每指偏差都不超过参考容差才匹配。正确姿态持续约一秒后计数；一直保持同一姿态不会重复加次数，需要离开后重新进入。

“姿态尚未匹配”表示没有命中参考，不应直接理解为陶艺动作错误。当前界面还不能告诉你具体哪根手指偏差最大，遇到问题先核对参考数值和校准时序。

语音开关在首页反馈卡和设置页。当前播报条件为：**语音已开启、练习正在进行且未暂停、反馈从非匹配进入匹配**。保持不变、未匹配、已结束练习均不会反复播报。浏览器或系统输出设备也会影响实际声音；当前尚无独立试听按钮。

## 7. 报告与导出

结束练习后查看时长、采样帧数、匹配次数及时间线。历史报告在“学习记录”。报告可导出 JSON、打印；有原始日志时可导出日志。首页“导出数据”导出当前页面持有的采样数据，不应当作全部历史的备份。

报告反映采集和参考匹配情况，不是教学能力认证。持续匹配次数与帧数不同；没有连续采样的报告不能作为连续动作识别成功的证据。

## 8. 连接安卓 App

电脑和手机连接同一局域网。在“设置 → 两端协同 → 查看局域网地址”获取电脑地址，填写到 App 的“连接电脑”，例如 `192.168.1.20:4180`。手机中不能使用 `localhost`，它指向手机自己。

## 9. 常见问题

| 现象 | 检查与处理 |
|---|---|
| 没有弹出校准 | 回到训练工作台，点击右侧“重新校准”；左侧“设备与校准”是导航入口 |
| 蓝牙连上但无曲线 | 检查手套供电、采样时效、是否为模式0；必要时断开重连 |
| 一根手指固定500或2500 | 查看佩戴和接线，重新核对两端姿态及变化；不要马上认定传感器坏了 |
| 做对了仍不匹配 | 检查是否录入了该姿态、旧参考是否因校准失效、五指值及容差是否合理 |
| 完全没有语音 | 确认练习进行中、语音开启且出现一次新匹配；再检查系统扬声器及浏览器静音 |
| 命令超时 | 先查看回执并重连核对设备状态；超时不保证命令未执行，避免连续重复提交 |
| 手机连接失败 | 确认电脑服务仍运行、IP与端口正确、同一网络且没有访客网络隔离 |

## 附录：新电脑安装与维护

源码仓库不包含依赖和前端构建结果。安装 Node.js（项目 App 工具链使用22+）及可用 Python，然后在 `01_软件工程/pottery-studio` 执行：

```powershell
npm ci
npm --prefix desktop ci
npm --prefix mobile ci
python -m pip install --target hardware/python-deps -r hardware/requirements.txt
npm test
npm run build
npm start
```

必要时用环境变量 `POTTERY_PYTHON` 指定 Python。业务文件是 `core.mjs`，服务入口是 `server.mjs`，蓝牙及设备协议位于 `hardware/`，桌面界面位于 `desktop/src/`。

个人设置、参考、校准和报告在 `data/`；备份时先结束练习并停止服务，再复制整个目录。该目录不上传源码仓库。不要在实时练习中手动修改 JSON。电脑服务意外退出后的会话自动恢复尚未实现。
