# 非遗之手 · Android 0.2.0

本目录的 APK 是独立安卓 App，界面已内置。手机作为电脑工作台的辅助端使用。

## 安装与连接

1. 将 `非遗之手-0.2.0-debug.apk` 传到安卓手机，打开安装。系统若提示，需要允许当前文件管理器安装你选择的这个应用。
2. 电脑双击项目根目录的 `启动非遗之手.cmd`。
3. 手机和电脑连接同一 Wi-Fi。电脑工作台进入“设置 → 两端协同 → 查看局域网地址”。
4. App 右上角设置中填写电脑地址并连接，例如 `192.168.1.20:4180`。手机不要填 `localhost`。
5. 在电脑把手套通过蓝牙连接好。App 中查看设备，进入练习，开始 / 暂停 / 结束并保存报告。

若无法连接，先确认电脑程序运行、两个设备可以在局域网互通、Windows 防火墙允许该程序通过专用网络。校园 Wi-Fi 可能隔离设备，可换同一热点测试。不要把虚拟网卡地址作为手机连接地址。

## 说明

- 最低 Android 7.0；需要正常的系统 WebView。本包为 debug 签名的内部联调版本，未上架。
- 手机不直接抢占手套蓝牙，继续采用“手套 → 电脑 → 手机”的方案。
- 校准端点仍在电脑采集。手机新录入的是软件参考，不覆盖硬件模板槽位。
- 断网可查看最近同步的 50 份报告。实时数值不会从缓存伪造；离线不能修改练习。
- 关闭 App 不会结束电脑上的练习。需要结束时按 App 或电脑的结束按钮。
- 已完成编译、签名、业务测试及浏览器界面验收；实际安卓手机的安装、分享、后台恢复需要真机核验。
