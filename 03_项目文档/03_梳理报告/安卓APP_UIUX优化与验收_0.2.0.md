# 安卓 App 0.2.0：UI/UX 优化与验收

2026-09-14。针对上一版“原型感明显、主操作不突出、信息偏密”的反馈，重做移动端页面与操作层级，沿用电脑采集、手机辅助的架构。

## 页面与交互

| 页面 | 改动 |
|---|---|
| 首页 | 深绿与暖白视觉、陶艺主视觉、分栏课程卡、清晰的准备状态和下一步按钮；有进行中练习时提供返回入口 |
| 设备 | 独立设备展示、电脑和手套连接状态、按当前情况给出操作引导；曲线与技术说明折叠 |
| 连接 | 地址输入、同一 Wi-Fi 与工作台启动说明、键盘提交、就地报错、视频失败可重试 |
| 练习 | 示范角度切换、计时和计数突出显示；开始、暂停、继续、结束固定在底部；缺少连接时按钮引导连接 |
| 报告 | 时长、帧数、匹配次数和轨迹分层展示，备注单独呈现，保留分享和再次练习入口 |
| 我的 | 练习汇总、清晰的记录列表、联调记录标识和隐藏筛选 |
| 通用 | 保留返回历史与滚动位置；弹层管理焦点、Escape 关闭、背景禁用；提高次要文字字号与对比度，适配窄屏和系统安全区 |

展示层拆入 `src/StudioView.jsx`，数据同步与命令仍由 `src/App.jsx` 管理。样式统一在 `src/studio.css`，移除了未使用的旧样式与旧页面辅助代码。

## 本次验证

- `npm test`：8 项全部通过，包括实际 Studio 核心的开始、匹配、暂停、恢复、结束契约，以及断线与缓存边界。
- 浏览器 393×852：检查首页、设备、连接、练习、我的与报告的实际截图。
- 浏览器 320×640：检查窄屏练习控制区、结束弹层；无水平溢出，按钮可见并可操作。
- 地址表单：不带 `http://` 的地址可连接；清空后回车显示明确错误，不切换主机。
- 独立 4191 测试主机：合成数据完成开始 → 暂停 → 继续 → 备注 → 结束 → 报告。生成 1 份隔离报告，66 秒、327 帧、2 次匹配；不是硬件测量或陶艺成绩。
- 弹层：Shift+Tab 循环到保存按钮，Escape 取消，焦点返回结束按钮，取消没有结束练习。
- 导航：从首页滚动 106 像素后查看报告，返回仍为首页且滚动位置为 106 像素。
- 断线：停止独立测试主机后显示离线提示；合成报告仍可从缓存读取，筛选可用。
- 验收结束后恢复实际主机。真实数据仍为 1 份报告、1 个软件参考、无当前练习；原报告仍为 96 秒、481 帧、1 次匹配。
- Android `:app:assembleDebug` 成功，versionCode 2 / versionName 0.2.0，最低 API 24、目标 API 36；APK v2 签名验证通过。
- iOS 工程同步了新版页面资源，未在 Windows 编译 IPA。

浏览器验收图存放在 `06_整理工具与核验/审阅证据/2026-09-14/App-0.2-*.png`。本次未接入安卓真机，因此不把浏览器检查当成手机安装、系统分享、软键盘和后台恢复的实测结果。
