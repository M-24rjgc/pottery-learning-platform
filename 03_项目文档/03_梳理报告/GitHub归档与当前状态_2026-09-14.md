# GitHub 归档与当前状态

项目已上传到公开仓库 [M-24rjgc/pottery-learning-platform](https://github.com/M-24rjgc/pottery-learning-platform)，主分支为 `main`。首次以私有仓库建立，后按用户要求公开。首次归档提交为 `c935066`，包含302个Git条目（含硬件子模块）。本次归档重新运行的电脑端26项、App端8项测试均通过。

## 分区与恢复

- `01_软件工程`：电脑主机、手机网页、微信小程序和 Capacitor 安卓/iOS 工程。
- `02_硬件工程`：上游硬件源码作为 Git 子模块固定版本；原上位机交付副本保留。
- `03_项目文档`：原始文档、开发计划、硬件梳理和联调记录。
- `04_素材资源`：视频、界面原型、插画及硬件资料。
- `05_交付归档`：原始交付和安装说明；APK 与源码压缩包在本地保留，适合通过 Release 附件分发。
- `06_整理工具与核验`：可复用工具和说明；本机日志、提取缓存、审阅照片不进入源码历史。

克隆时使用 `git clone --recurse-submodules <仓库地址>`；已克隆则执行 `git submodule update --init --recursive`。硬件上游来源为 https://github.com/zwt383/pottery-learning-glove ，固定提交 `8ae9975b31dee99c2eea70439d73d69d056a0d62`。不修改上游远端及历史。

按各工程 README 安装依赖、构建及启动。依赖目录、构建产物、安卓 SDK/JDK、本机路径配置与签名密钥不纳入版本管理。`pottery-studio/data` 是个人模板、校准与练习报告，保持本地，不随源码上传；新机器需要重新校准和录入自己的参考。

## 已实现与验证边界

电脑主机通过蓝牙接收五路数据。首页“重新校准”可就地弹出图示、实时读数及曲线，按握拳、张开、检查与保存推进。已有 26 项业务/硬件离线测试通过，前端构建通过；不代表所有实物场景均已验收。

安卓交付基线为 0.2.0，0.3.0 视觉方案已撤回。iOS 工程存在，未交付可安装签名包。微信真机仍缺正式 AppID。

## 尚待开发的问题

1. 当前匹配是五路静态姿态比较，并非视频中的完整揉泥动作识别。
2. 重新硬件校准后旧软件模板被标记 `needsReview` 并排除匹配，但手势管理尚未清楚展示失效状态。
3. 当前有效“按压”参考容差为每指 ±100，实时数据偏差较大；需要在用户保持正确姿态时重新核对录入，不能单靠放宽容差宣布修复。
4. 工作台尚未显示逐指偏差及最接近参考的解释。
5. 语音仅在未暂停练习内进入匹配时触发；未匹配提示、语音试听、错误反馈仍待补齐。扬声器实际发声未在本次归档中验证。

以上问题是后续工作，不作为已完成能力宣传。归档不更改硬件模板或个人数据。
